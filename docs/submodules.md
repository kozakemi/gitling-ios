# 子模块工作流

在仓库“操作 → 子模块”中查看状态、初始化或更新。存在未完成任务时，仓库顶部显示“恢复子模块更新”，应用重启后仍可进入。

## 操作语义

- **初始化子模块**：将子模块配置写入父仓库本地配置，不下载或检出文件。递归初始化只处理已能打开的子仓库；尚未克隆的子模块，其下一层需要更新检出后才能发现。
- **更新子模块**：检出父仓库**索引**中的 gitlink 提交，不追踪远端分支最新版，不暂存父仓库的 gitlink。目标对象在本地时直接使用；缺失时才从该子模块远端获取。
- **初始化缺失的子模块**：开启时更新会初始化并克隆缺失项；关闭时跳过未检出的子模块。
- **递归处理子模块**：更新父层后读取实际检出的 `.gitmodules`，继续处理新发现的嵌套模块。循环或过深的仓库结构会被拒绝。
- 状态分别显示未初始化、已初始化尚未检出、需要更新、与目标版本一致和本地修改；显示路径、远端、索引目标及当前 HEAD。无法安全打开的模块单独显示错误。

## 数据保护与失败恢复

更新前检查现有子模块及其已检出的后代，包含已暂存、未暂存、未跟踪文件和未完成的 Git 操作。即使关闭递归，也检查嵌套脏工作区，避免检出父层时覆盖它。忽略子模块状态的配置不能绕过此检查。检出使用 SAFE 和 DONT_OVERWRITE_IGNORED；不会强制重置，也不会删除阻挡操作的普通目录、符号链接或忽略文件。

父仓库的 HEAD、索引和其他工作文件不作更改。路径按字面处理；对子模块名称、工作目录、`.gitmodules` 和 Git 数据目录进行边界校验。支持名称与目录不同，以及 Git/libgit2 使用的按名称或按路径存放的模块数据目录。外部关联工作区使用实际书签并持有访问作用域，失联时拒绝退回内部目录。

每个父仓库的 `.git/gitling-submodules.json` 在步骤前后原子记录选项、目标、URL、当前路径及完成项，不记录密码、令牌或私钥。失败和应用退出后保留所有本地 Git 数据；重试沿用保存的选项，只继续剩余步骤。父索引、配置或工作区发生变化，或已经完成的模块 HEAD 被外部改动时，拒绝继续，要求先结束旧任务并检查状态。损坏的任务记录也可以明确结束。

“结束本轮更新”只移除任务记录，保留已完成的检出、已下载对象和文件，**不回滚**。移动已有子模块 HEAD 前，旧提交保存在该子仓库的 `refs/gitling/submodule-backups/<任务 ID>`，结束或完成任务不会删除此引用。没有实现跨多个仓库的原子回滚；不存在“后一个失败就强制重置所有模块”的行为。

## 远端凭据

每个模块按自己实际访问的远端匹配账户；相对 URL 根据所在父仓库的远端解析。HTTP(S) 账户按协议、主机、端口和平台实例路径匹配。父仓库关联账户只有在匹配目标时才优先使用，不直接把父令牌传给其他远端。

页面可按远端选择已保存账户，或输入仅用于当前页面的用户名及密码/令牌覆盖值。SSH 密钥按 SSH 主机和端口选择；父仓库关联密钥仅对相同 SSH 地址自动生效，不把 HTTP 令牌用于 SSH。新发现的嵌套主机需要指定密钥时，可在失败后选择并重试。

凭据回调拒绝跨主机、端口、协议降级或跨实例导致凭据变化的重定向；限制重复凭据请求。继续使用证书校验和已有 SSH 主机密钥信任检查。URL 中直接嵌入密码会被拒绝，任务记录和错误提示不保存该密码。

## 性能与范围

子模块状态在专用页面按需加载；首页、历史页面不递归扫描子模块。任务进度入口仅检查记录是否存在。状态和更新在后台执行，网络传输不占用全局 Git 锁，仓库写锁阻止同一工作区并发写入。为保护本地修改，更新前的脏检查仍需要查看已检出后代的状态。

不提供跟随远端分支的 `--remote` 更新、自定义更新命令、子模块内自动 merge/rebase 或强制覆盖。子模块中的 Git LFS 内容不会在本轮自动执行额外的 LFS 下载。已有不受支持的导入、LFS 和真机验证限制仍适用。

## 回归验证

新增 23 项 `SubmoduleTests`、5 项凭据路由回归和1项中/英/日、240～951 点宽度及无障碍字号布局回归。全部采用本机临时仓库和既有离线缓存，不访问远端 Git 服务器。凭据匹配、隔离和重定向通过策略测试验证，没有对实际 HTTP/SSH 服务器执行认证集成测试。

在隔离 `Gitling Duo Layout QA` 模拟器中，使用已有工作区和新增本地测试源完成以下手动验证：

1. 外屏进入子模块页，显示名称与中文长目录路径不同的模块。初始化后显示“已初始化，尚未检出”，不下载文件。
2. 递归更新完成父层及嵌套层，第三个本地源缺失时暂停；记录保存两个完成项、递归选项和失败路径，父仓库索引字节未变。
3. 终止并重启应用，从仓库顶部恢复入口重新打开；显示两个完成项与保存的选项。将本地源放回后展开 Duo，页面保持，再重试剩余步骤。
4. 三个 HEAD 均与父层索引目标一致，任务记录清理，父仓库 HEAD 和索引字节完全未变。
5. 手动给嵌套模块加入本地修改，再从界面更新：明确拦截并显示完整路径；修改未丢失、父索引未变，未创建新的任务记录。隔离 QA 仓库保留该编辑用于检查。
6. 明确结束旧任务的确认页说明只清除任务，不回滚或删除文件。操作后已有检出内容保留。XCTest 重装造成模拟器数据容器变化时，旧记录也会要求先结束并检查，不静默换工作区。
