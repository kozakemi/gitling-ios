# 复制导入已有仓库

日期：2026-11-10。

## 使用方法

首页添加按钮 →「复制导入」→ 选择仓库根文件夹 → 填写本地名称 →「导入」。普通仓库需要包含实际 `.git` 目录；裸仓库可直接选择其根目录。

导入内容保存在 Gitling 内部工作区，源文件夹不作为新工作区关联，也不会移动或清空。普通仓库不执行 checkout，以保留暂存区、暂存后的再次编辑、未跟踪文件和被忽略的文件。

## 保留的数据

完整目录复制包含工作区、隐藏文件、Git 对象和 pack、全部引用、标签、索引、Stash、reflog、未引用对象以及仓库内的其他 Git 数据。工作区符号链接保持为链接，不跟随复制链接指向的外部内容。

只在副本中将 `core.worktree` 改为相对于 `.git` 的路径，并设置普通工作区模式，避免导入后仍指向源目录。只读源保持原权限，副本补充所有者读写权限并保留执行位，以便后续编辑与 Git 操作。

裸仓库的全部 Git 数据放入副本的 `.git`，再离线检出 HEAD，成为可编辑仓库；空裸仓库也可导入。过程中不会执行 fetch/pull、Git hooks、子模块更新或 LFS 下载。原有远程配置随 Git 数据保留。

导入成功后清理同名旧仓库遗留的工作区书签、账户/SSH 关联和详情缓存；失败时保留这些关联。系统或 Keychain 凭据不会从源目录迁移，后续同步使用 Gitling 的账户与凭据流程。

## 冲突与失败处理

1. 在创建目标或锁目录之前检查源/目标重叠、非法名称，避免把副本递归写入源目录。
2. 已存在的目标目录、文件和悬空符号链接均不覆盖。
3. 在 `repositories/` 之外的私有事务目录复制，未完成的副本不会出现在仓库列表，也不会被存储发布流程备份。
4. 通过 File Coordinator 和临时 security scope 读取用户选择的目录。前后对比文件身份、大小、类型及 mtime/ctime，发现复制期间的源变化则终止，不回滚用户在源上的新修改。
5. 核对复制前后的文件清单、文件大小、类型与链接目标；校验 Git 根目录、HEAD 树、引用目标和索引。这里不是对全部对象执行完整 `git fsck`。
6. 目标副本完成准备后，用 `RENAME_EXCL` 同卷原子发布。即使复制期间出现同名目标，也不覆盖它。
7. I/O 错误、取消、复制不完整、Git 校验失败和目标竞争均清理本次事务目录；只清理本次拥有的临时副本，不删除源或已有目标。

检测到 Git 锁、外置 `.git` 文件/链接、commondir、Git 元数据符号链接、非空 alternates/http-alternates 或 promisor 对象依赖时，首版明确拒绝。此类仓库不能通过普通目录复制获得独立的完整 Git 数据，需要后续的专门导入支持。

## 测试

`RepositoryImportTests` 包含 17 项回归，覆盖完整目录状态、Stash/标签/reflog/未引用对象、绝对 worktree 路径、只读源、空仓库、部分复制及取消、复制损坏与漏文件、源并发编辑、目标竞争和悬空链接、外部 Git 依赖、重叠路径、全局 Git 锁响应性、书签导入与旧关联处理。

复用已经下载的 Js_ms_rtos 离线夹具，新增两项真实仓库导入验证：

- 裸仓库转换后保留 14 个分支和 408 个提交，pack/对象数据不变；在新副本提交后，源内容摘要仍不变。
- 普通工作区带有同一文件的暂存与未暂存版本，导入后状态和 diff 一致，源内容摘要不变。

最终完整回归：iOS 18.6、iOS 27.0 均为 **77/77 通过，无跳过**；真机 Release 配置构建成功。本地化检查和 `git diff --check` 通过。真机文件提供方交互尚未手动实测。

## 性能与离线复用

文件复制、清单扫描和源变化检测不持有 Git 全局锁，所有耗时工作在后台执行；回归测试在暂停复制时验证其他仓库元数据仍可读取。Git 校验与裸仓库检出沿用现有 libgit2 串行锁。

真实夹具为 1,913 个文件、约 52 MiB 工作区、约 20 MiB bare 缓存。核心流程单次采样如下：

| 环境 | 普通工作区复制导入 | 裸仓库复制并检出 |
| --- | ---: | ---: |
| 最初单模拟器验证 | 0.61 秒 | 1.04 秒 |
| 最终并行验证，iOS 18.6 | 0.89 秒 | 1.46 秒 |
| 最终并行验证，iOS 27.0 | 0.81 秒 | 1.55 秒 |

计时包含复制、清单检查、Git 准备、原子发布和事务清理；不含夹具准备、测试的内容摘要计算、Store 后续备份/刷新或界面首帧。没有设置固定毫秒级通过阈值。

所有真实仓库测试使用保留的本地夹具；本轮没有再次克隆服务器仓库，也没有向服务器 fetch/pull。普通环境未安装私有夹具时，离线专用测试会明确跳过，不会自动下载。
