# 提交历史与文件树搜索

更新日期：2026-11-11。

## 使用与范围

仓库的“提交”和“文件”页分别提供搜索入口。搜索独立遍历数据，不筛选当前已加载列表。

- 历史可选择全部字段、提交说明、作者或 OID。说明包含完整提交正文，作者包含姓名和邮箱；文本为不区分大小写的字面子串。OID 支持完整值及十六进制前缀，专用字段会拒绝无效输入。
- 历史范围可选当前 HEAD、全部分支与标签，以及从原页面带入的指定引用。全部范围包含本地分支、远端跟踪分支、标签和 HEAD 的可达提交；不搜索 reflog、Stash、内部备份或不可达对象。重复可达提交仅返回一次；非提交标签跳过，损坏引用或对象明确报错。
- 文件按文件名或相对路径进行不区分大小写的字面子串匹配，递归整个工作目录，包含隐藏、忽略和未跟踪文件。不读取文件内容，不执行全文检索。
- 文件搜索排除所有 `.git` 目录、符号链接和特殊文件，递归深度上限128。外部工作区授权失效明确报错，不回退到内部副本或重建目录。打开结果时重新核验路径，仅预览不超过256 KiB的普通 UTF-8 文件。

## 性能与一致性

输入防抖250 ms；扫描和分页在后台执行。输入、字段、范围或仓库修订变化会取消旧任务，代次校验防止迟到结果覆盖新查询。离开页面也取消扫描。结果显示累计检查数量和是否还有下一页。

历史游标使用独立只读仓库句柄和持续 revwalk，后续页面继续遍历，不重复从头扫描，也不占用仓库写锁。引用起点在查询创建时固定，刷新查询后才使用新引用。文件使用描述符相对遍历和不跟随链接的打开方式，保留外部目录访问授权，并检查根目录身份；目录变化期间的结果不构成原子快照，需重新搜索获得最新结果。

分页每次最多500条，界面按需加载；这限制单次结果分配，但全部结果累计加载后仍占用内存。无匹配的查询需要遍历完整范围，耗时随历史和目录规模增长。安全预览也用于普通文件浏览入口。
