## 性能与离线测试原则

已有真实仓库缓存为 `build/performance-fixtures/Js_ms_rtos.git`，包含14个分支、408个提交。后续测试复用该缓存及本机临时仓库，不自动重新拉取服务器。缺少离线夹具时，相关性能测试明确跳过，不自行联网；解释测试结果时需同时检查跳过项。

已实施的性能改进包括：页头避免工作区扫描、只刷新受影响仓库、文件/Git 读取移到后台、历史分页与详情缓存、LFS 流式哈希与缓存、子模块页面按需加载。子模块网络传输不占用全局 Git 锁，但其他既有同步操作的锁竞争仍需持续测量。

## 已知边界与待验收事项

1. **真机与外部提供方**：尚未完成真机、iCloud/第三方 File Provider、第三方编辑器完整往返及长期操作验收。模拟器验证不替代这些检查。
2. **Duo 旧文件入口**：“我的 iPhone → Gitling”仍有模拟器系统映射异常。已验证的入口是“浏览 → Gitling”；没有宣称修复旧系统入口，也不公开 Documents 中的所有杂项文件。
3. **远端认证验收**：子模块凭据隔离、端口/协议/实例路径匹配及重定向保护已回归；尚未对真实 HTTP/SSH 服务器执行完整子模块认证集成测试。后续应优先使用本地测试服务器，减少实际服务器负载。
4. **导入**：依赖外置 `.git`、共享对象库或 promisor 对象的仓库仍明确拒绝，避免产生不完整副本。
5. **逐文件恢复与 LFS**：暂拒绝将 LFS 文件通过该入口恢复为指针；不会删除未跟踪文件或递归移除目录。
6. **子模块**：重试保留已完成部分，结束任务只清除记录，不提供多仓库原子回滚、强制覆盖或 `--remote` 跟踪更新。
7. **Tag**：本轮只做浏览、详情与检出；不含创建、删除、推送和签名验证。检出不自动更新子模块或下载 LFS 内容。
8. **文件查阅与 Blame**：文件历史及 Blame 限首父链，不覆盖所有合并父分支或复制检测；Blame 默认5000提交/64 MiB逻辑读取估计，超限标记来源可能更早。单次同步 libgit2 调用不能强制中断，串行任务可能等待当前调用；预算不是CPU或峰值内存硬限制。尚需真机与Duo手动界面验收。
9. **其他能力**：SSH 密钥仍仅支持导入，缺少生成/导出及 known_hosts 管理；控制台命令集有限；不支持交互式 rebase 和自定义 merge driver。这些限制不全部等同于参考工程已经具备的功能差距。

## 后续优先级

P1 为优先验收或影响完整使用的事项；P2 为下一批功能补齐；P3 为便利性增强。以下是建议顺序，不表示已经开始实施。

| 优先级 | 工作项 | 当前差距与交付重点 |
| --- | --- | --- |
| P1 验收 | 真机文件与认证流程 | 验证外部目录授权、编辑器往返、挂起/恢复、子模块多远端认证及实际耗时；优先本地服务和离线数据 |
| P2／下一个开发项 | 任意两个提交比较 | 当前主要是单提交及工作区/索引差异，需要完整的两提交选择与比较入口 |
| P2 | 通用自建 Git 平台账户 | 完善 Gitea/Forgejo 等平台的账户及仓库列表体验；与已有手工 URL 传输区分 |
| P2 | SSH 管理 | 密钥生成、导出和 known_hosts 管理，并保留现有私钥及口令保护 |
| P3 | 控制台扩展 | 在现有有限命令集上接入更多已实现操作，不绕过写锁和数据保护 |
| P3 | 仓库组织 | 置顶、自定义分类标签和筛选；这里的分类标签与 Git Tag 是不同功能 |
| P3 | 桌面小组件与个性化 | 仓库状态小组件及更多外观选项，按 iOS 平台习惯实现 |
