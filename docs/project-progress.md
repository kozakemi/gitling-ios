## 已知边界与待验收事项

1. **真机与外部提供方**：尚未完成真机、iCloud/第三方 File Provider、第三方编辑器完整往返及长期操作验收。模拟器验证不替代这些检查。
2. **Duo 旧文件入口**：“我的 iPhone → Gitling”仍有模拟器系统映射异常。已验证的入口是“浏览 → Gitling”；没有宣称修复旧系统入口，也不公开 Documents 中的所有杂项文件。
3. **远端认证验收**：子模块凭据隔离、端口/协议/实例路径匹配及重定向保护已回归；本地HTTP smart Git克隆/fetch/认证重试已集成验证，实际fixed_unit_queue服务器完成认证、目标引用核对及Duo隔离仓库一次更新，下载结果已缓存。真实SSH、用户原有仓库更新及真机多远端流程仍待验收。
4. **导入**：依赖外置 `.git`、共享对象库或 promisor 对象的仓库仍明确拒绝，避免产生不完整副本。
5. **逐文件恢复与 LFS**：暂拒绝将 LFS 文件通过该入口恢复为指针；不会删除未跟踪文件或递归移除目录。
6. **子模块**：重试保留已完成部分，结束任务只清除记录，不提供多仓库原子回滚、强制覆盖或 `--remote` 跟踪更新。
7. **Tag**：本轮只做浏览、详情与检出；不含创建、删除、推送和签名验证。检出不自动更新子模块或下载 LFS 内容。
8. **文件查阅与 Blame**：文件历史及 Blame 限首父链，不覆盖所有合并父分支或复制检测；Blame 默认5000提交/64 MiB逻辑读取估计，超限标记来源可能更早。单次同步 libgit2 调用不能强制中断，串行任务可能等待当前调用；预算不是CPU或峰值内存硬限制。尚需真机与Duo手动界面验收。
9. **提交比较**：直接比较两棵树，不提供merge-base/三点比较、复制检测或组合merge diff；缺失对象不联网补齐。5000文件、256 KiB单侧blob、80 KiB补丁及重命名候选预算均明确提示；底层同步调用没有硬CPU/峰值内存保证，详见专题文档。
10. **其他能力**：SSH 密钥仍仅支持导入，缺少生成/导出及 known_hosts 管理；控制台命令集有限；不支持交互式 rebase 和自定义 merge driver。这些限制不全部等同于参考工程已经具备的功能差距。
