# 任意两个提交比较

日期：2026-11-12。基于既定计划实施，独立于工作区/索引 diff 和单提交详情。交付范围和最终验收结果如下。

## 使用与语义

仓库的提交历史工具栏新增“比较提交”。明确选择“基准提交 → 目标提交”，支持 HEAD、本地分支、远端跟踪分支、轻量/附注及嵌套标签、唯一 OID 前缀（至少7位）和完整40位 OID。选择器同时提供按提交说明、作者、OID 检索完整可达历史及持续分页；不限定于仓库页面已加载的300条。

每次选择解析并保留完整提交 OID；引用之后移动不会改变已选对象。显示完整标识，交换两端同时反转文件增删、重命名方向和补丁行统计。重新选择指向同一 OID 的其他引用或交换相同提交时保留有效结果，不会一直停留在“准备比较”。

直接比较两棵指定提交树，不自动计算 merge-base。相同提交、非祖先和合并提交均按此语义处理；合并提交不是组合 diff。展示新增、修改、删除、模式/类型变化与启发式重命名，按需查看单文件补丁。

只读取本地 Git 数据库：不检出、不改变 HEAD/引用/索引/工作文件，不使用外部工作区授权，不访问远端。失效的外部目录不会被重新创建。历史符号链接只显示记录的目标；gitlink 只显示记录的 OID，不打开或更新子模块。单文件补丁用已检查大小、已加载 blob 的纯内存 `git_diff_buffers` 生成，不从当前 `.gitattributes` 或索引决定文本差异；无索引、损坏索引及当前 `* -diff` 属性回归均覆盖，修改内容后的重命名检测也有独立回归。二进制、非 UTF-8、过大、缺失对象和目录变化分别提示，不能冒充无差异；非 UTF-8 不提供十六进制预览。历史 LFS 指针也不触发下载。

## 资源与取消

| 项目 | 默认上限与行为 |
| --- | --- |
| 文件列表 | 最多持有5000条；生成回调跳过后续条目并明确标记截断，不先创建整份列表再切片 |
| 单侧 blob | 对象头先检查，超过256 KiB不加载正文 |
| 单文件补丁 | 回调累计最多80 KiB UTF-8；按完整行记录停止，不先生成完整 patch 再截断；超限标记及部分行数统计单独显示 |
| 重命名 | 最多256候选、累计64 MiB逻辑候选字节，每个 blob 也受256 KiB限制；重复 OID 的候选字节仍累计，gitlink 也计入候选数量；没有增删候选对时不运行检测 |
| 端点元数据 | 最多检查32个标签/提交对象，每个对象头限制1 MiB，非提交/歧义/缺失明确拒绝 |
| 页面后台任务 | 共用串行读取队列，不累计缓存所有文件补丁；输入/方向变化和离开页面取消旧 token，跳过已取消的排队读取 |

libgit2 tree-diff notify/progress 和补丁回调合作中止，回归实际验证生成第2个条目及首个补丁行回调时停止，不只是完成后丢弃结果。页面同时检查 generation、固定端点对和文件标识，防止迟到结果覆盖新选择；选择器输入/检索条件变化也取消旧解析。

文件上限约束存储条目数，不意味着到达5000条后不再遍历树。对象读取、pack delta、树元数据及 `git_diff_find_similar` 内部处理没有硬 CPU/峰值内存保证；重命名同步调用进入后需返回，串行队列的新请求可能等待它，候选预算只是估计边界。当前不检测复制，不提供 merge-base/三点比较、组合 merge diff 或网络补全对象。

## 布局与共享 diff 字体

两端完整 OID、方向和长路径可换行/选择；列表把控件放在顶部首个区块，空白、加载和错误不再使控件居中。单文件页头高度受视口限制，长元数据和无障碍字号时可内部滚动，给 diff 正文保留空间；短页头不占满最大高度。

Duo 实际大字号检查发现原共享 UIKit diff 未跟随 SwiftUI 字号，已修复 `DiffTextView` 的动态字号依赖和显式 trait 映射，保持等宽、可选择、只读及高亮，避免二次缩放。该修复也适用于既有单提交和暂存/未暂存 diff。中/英/日新增89条翻译；比较中的“基准提交”采用独立键，保留冲突页“Base=共同祖先”的原翻译。

## 跨运行时的测试产物签名

实际严格签名检查发现：共用 `build/TestDerivedData` 从27.2切回18.6时，Xcode重建了裁剪后的 `Assets.car`，却未更新 `CodeResources`；文件哈希与旧QA签名一致，而与当前资源不同。不能把单纯测试成功当成最终可安装签名验收。

`./scripts/test.sh` 现默认使用 `build/TestDerivedData-<目标UDID>`，不改变白名单，不创建模拟器。两台设备分别从隔离缓存重新完整测试并校验构建产物与已安装应用的 `codesign --verify --deep --strict`；覆盖 `TEST_DERIVED_DATA` 时也须保持分开。旧共享目录只保留历史日志，不作为最终安装产物。测试宿主重装会迁移容器UUID，手动只读摘要按当前QA容器重新定位后仍核对原来的相对路径/内容摘要，不把旧路径失效误当作仓库丢失。
